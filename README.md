# attack-tool
Attack Tool is a multi‑platform OSINT and CyberSecurity console application designed to provide fast access to investigation tools, network utilities, social web shortcuts, and security analysis features.
It runs on Windows, Kali Linux, Ubuntu, Termux (Android), and macOS.

The tool includes:

Holehe (email check)

PhoneInfoga (phone number OSINT)

Instaloader (Instagram data)

IPinfo lookup

WHOIS lookup

theHarvester

SpiderFoot
